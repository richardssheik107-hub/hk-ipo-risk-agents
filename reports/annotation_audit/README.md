# Expert Annotation Phase-1 Audit

This directory is generated by `scripts/audit_expert_annotations.py`.

The Phase-1 audit is deliberately **read-only** with respect to:

`expert_results/ipo_*/pass1/expert_annotation_v1.json`

It recomputes only frozen deterministic rules, reports policy ambiguity rather
than inventing a policy, and routes semantic risks to independent second-pass
review.

Generated files:

- `audit_summary.json`
- `risk_conflicts.csv`
- `policy_ambiguities.csv`
- `semantic_review_queue.csv`
- `per_case/<case_id>.json`

Audit statuses:

- `PASS`
- `HARD_DETERMINISTIC_CONFLICT`
- `INSUFFICIENT_INPUT`
- `EVIDENCE_INPUT_CONFLICT`
- `POLICY_AMBIGUITY`
- `SECOND_PASS_REQUIRED`

Run locally:

```bash
python scripts/audit_expert_annotations.py
pytest -q tests/unit/test_annotation_audit.py
```

Phase 1 must not create corrected annotations or any
`final/expert_annotation_v2.json` file.
