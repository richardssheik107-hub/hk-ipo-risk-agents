=1.0

## 4. 当前开放 hard Gate

### Gate B1 — M1 Risk Extraction：OPEN / P0

当前正式实测仍是旧 10-case governed **offline diagnostic baseline**：

```text
Risk Precision                         0.0%
Risk Recall                            0.0%
Risk F1                                0.0%
Real LLM cases                         0
```

metric-v1 不允许用大量 true negative 刷高 Accuracy。最终必须建立 positive Gold Risk Unit evaluator，primary families 固定为：

```text
redemption_rights
related_party_transaction
customer_concentration
supplier_concentration
cash_burn_pressure
```

`related_party_transaction` 只能 additive competition sidecar；`cash_burn_pressure` 是比赛 metric family，对应现有 `cash_runway` / deterministic cash-burn 计算，不静默改写 frozen risk registry。

关闭 B1 需要：

```text
real-LLM Development benchmark
+ metric_protocol_version = v045_competition_metric_protocol_v1
+ official_aligned_accuracy >=0.80
+ positive_recall >=0.82
+ macro_f1 >=0.82
+ per-risk support/metrics
+ Blind=false
```

内部优化目标是 Accuracy >=0.85。
