## 4. Current real-case hardening finding

A v0.4.5 AI smoke on `2410.HK / 浙江同源康医药股份有限公司 / 2024-08-20` surfaced one structured integration error:

```text
stage       market_intelligence
component   market_intelligence
code        component_failure
message     'NoneType' object has no attribute 'missing_reason'
recoverable true
```

### Root cause

`governed_pr_b_core` is valid even when optional C-lane Extended readiness is not supplied. In that Core-only state, expected MarketRegime inputs such as HSI return, volatility and turnover can be absent from `MarketContextView.observations` entirely. The Skills previously used a missingness comprehension that checked `item is None` but still dereferenced `item.missing_reason`.

### Fix contract

Both Market Skills now use:

```text
object exists + unavailable → preserve its governed missing_reason
object absent               → source_unavailable
object available            → use the governed value only
```

Regression coverage explicitly exercises Core-only context. This fix does **not**:

- fill absent Extended features with zero;
- synthesize HSI, volatility, turnover or industry values;
- change IPO Heat / Market Regime thresholds;
- alter PIT rules;
- relax Market LLM numeric-fact restrictions.

### Acceptance consequence

The code defect is closed only when CI passes this branch/PR. The 2410.HK real case remains **RE-RUN REQUIRED** after pulling the merged fix. A code-level regression pass must not be reported as a real-case E2E pass.

## 5. Core-only vs Extended Market runtime

Default settings keep `market_extended_readiness` empty. Therefore the competition runtime is allowed to operate as:

```text
Market-X Core available
+ recent IPO context available
+ Extended HSI / turnover / volatility absent
→ IPO Heat may still be available
→ Market Regime may be INSUFFICIENT_DATA
→ Market Intelligence remains a valid deterministic partial result
```

If a governed local Extended readiness artifact is available, it may be supplied through config or `IPO_RISK_MARKET_EXTENDED_READINESS`. Missing industry returns remain `INDUSTRY_MAPPING_PIT_BLOCKED` unless a legitimate historically effective mapping exists.
