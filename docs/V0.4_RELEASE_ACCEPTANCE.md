## 10. Known limitations

提交与答辩必须主动说明：

- G2 自定义目标未达到；
- real LLM gated 低于 best offline；
- strict schema / Evidence scope 下 LLM augmentation 存在结构化失败与负增益风险；
- source-edition / exact-anchor provenance 对部分 M2 有约束；
- Dynamic Market-X 超出受治理边界会诚实 unavailable；
- model score 未校准；
- remote LLM prose 不是 byte-for-byte deterministic；
- licensed PDF / raw EOD / CSMAR 数据不随公开仓库分发。

- `UNJUDGED != negative`；

- 无公司/股票/case/page/Gold-text 特判；

- model score != probability；
