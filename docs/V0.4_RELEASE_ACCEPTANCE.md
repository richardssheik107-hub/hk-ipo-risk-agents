```text

= REMOVED FROM RELEASE PLAN
```

- 不要求新增真人标注；

- 不影响 final package；
- 不得伪造 `M4 PASS`，直接标记为 `OPTIONAL / NOT_REQUIRED_FOR_RELEASE`。
