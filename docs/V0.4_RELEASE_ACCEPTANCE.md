## 4. Quality gap：Evidence bbox upstream grounding

当前 Evidence Viewer 可以按真实物理页渲染证据页，但 parser 尚不生成 `DocumentChunk.bbox`。

已测 2410.HK：

```text
parsed chunks              706
chunks with page           706
chunks with bbox             0
risk Evidence                2
risk Evidence with page      2
risk Evidence with bbox      0
```

UI 的降级是诚实的：没有 bbox 就不画框，不会自己猜坐标。

该项属于 **B（Evidence grounding）+ A（frozen provenance impact）**。因为增加 bbox 会改变 Evidence 内容/hash，所以不能由 UI 层修补，也不能无审计地回写 frozen PR-G/PR-H artifact。

当前赛题硬指标首先要求关键 Evidence 与可追溯来源；page grounding 已成立。若最终展示需要精确截图高亮，可在明确 versioning/provenance 后补齐 bbox，但它不得阻塞 B1/D1/E1 这些更高优先级硬 Gate。

## 5. Historical PR-H 与比赛 Gate 分离

历史 PR-H 仍保留其 frozen closure 语义：原始 frozen PR-F runtime 或 hash-bound sanitized handoff 若不可恢复，Model Channel 就不能伪造为 available。

当前变化：

- “至少 3 个真实 PDF”这一条件已经满足；
- authentic frozen PR-F per-case runtime/handoff 仍未恢复；
- 因此 historical PR-H 不应被重新写成 COMPLETE；
- competition runtime 可以诚实地以 `Model Channel = unavailable` 继续提交，不需要为了 UI 重训模型。
