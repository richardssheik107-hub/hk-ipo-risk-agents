## 0. Release Gate 不是研发阻塞器

从提交前加速模式开始：

```text
current-case stage completed / UI green
!=
competition release gate passed
```

普通 UI、API、Report、Trace、Evidence、adapter、projection、测试和其他 lane PR，只要 CI/contract 安全即可合并，不需要等待本文件所有 Gate 关闭。

相反，本文件任何未关闭项都必须在最终提交前真实补齐，且不能通过 UI 染色、mock、fallback 或 unavailable channel 冒充 PASS。

一个 current-case runtime 完成后，即使 optional Model / Market / real-LLM channel unavailable，产品阶段也可以显示“已完成”；该 channel 的真实 unavailable/fallback 状态必须同时显示，并且不改变下表 Gate 结论。
