# Planner → Executor Workspace

This directory persists reviewed engineering instructions independently of chat history.

```text
Planner
  ↓
DRAFT Plan
  ↓
Human / Web ChatGPT review
  ↓
APPROVED Plan committed to the repository
  ↓
Codex + execute-approved-plan
  ↓
Implementation and validation
  ↓
Execution Report
  ↓
Planner review
```

Chat messages are not formal engineering input. Codex may execute only the exact repository plan path supplied by the user, and only when its front matter says `status: APPROVED`. The Executor never approves or silently revises a plan.

## Directories

- `_TEMPLATE.md`: copy this to start a plan.
- `plans/`: store reviewed plans.
- `reports/`: store reports generated by Executors.
- `examples/`: contains DRAFT-only, business-neutral examples.

## Lifecycle

Allowed states are `DRAFT`, `APPROVED`, `EXECUTING`, `BLOCKED`, `COMPLETED`, and `SUPERSEDED`. A human or Planner controls plan state. The Executor records its execution state only in the report and leaves the plan untouched.

Validate a draft or approved plan:

```text
python scripts/validate_execution_plan.py docs/execution/plans/TASK-001.md
python scripts/validate_execution_plan.py docs/execution/plans/TASK-001.md --approved
```

Check all current Git changes against the plan:

```text
python scripts/check_execution_scope.py docs/execution/plans/TASK-001.md
```

Invoke the skill with an exact path:

```text
Use $execute-approved-plan to execute:
docs/execution/plans/TASK-001.md
```

## Portable installation

Copy these components to the same relative paths in another Git repository:

- `.agents/skills/execute-approved-plan/`
- `docs/execution/_TEMPLATE.md`
- `scripts/execution_plan.py`
- `scripts/validate_execution_plan.py`
- `scripts/check_execution_scope.py`

Also copy this README and the contract tests when practical. The destination repository supplies its own `AGENTS.md`, project-rule files, plans, validation commands, and file scope. The skill contains no business-specific assumptions.

For personal use, the skill directory may be installed at
`$HOME/.agents/skills/execute-approved-plan/`. This makes the skill discoverable
across repositories.

The current implementation is not fully self-contained. Each target repository
must still contain these runtime scripts:

- `scripts/execution_plan.py`
- `scripts/validate_execution_plan.py`
- `scripts/check_execution_scope.py`

Installing only the user-level skill will not make a new repository executable
until those scripts are present. A future self-contained distribution may remove
this repository-level runtime dependency. This repository does not install or
modify user-level Codex configuration.
