# v0.2.0 Real Document Slice

本版本完成从真实港股招股书PDF到已核验现金跑道风险的纵向闭环，并完成赛事数据治理基线。

## 主要能力

- PyMuPDF真实PDF解析与物理页码保留；
- 关键词Evidence检索与正式现金流量表定位；
- 现金及经营活动现金流确定性提取与归一化；
- 现金跑道Calculation、RiskItem和专用Verifier；
- verified-only规则评分和缺失市场数据降级；
- Service级真实E2E及Streamlit完整证据链展示；
- 565份招股书manifest、555/10行情覆盖和562/3官方IPO主数据桥接。

## 验收结果

- 独立全新克隆与Python 3.12.10虚拟环境安装通过；
- `pytest -q`：284 passed；
- Mock健康检查：completed，verified=3，pending=1；
- 赛事数据校验和compileall通过；
- 2410.HK：706个非空页Chunk，0解析错误；
- 现金页563：77,208人民币千元；
- 经营活动现金流页562：(83,918)人民币千元；
- 现金跑道：2.76个月，verified，critical，规则分90；
- Predictor故障时返回partial、结构化错误和失败日志，页面不崩溃。

## 已知限制

- 真实链路目前只覆盖现金跑道；
- Legal、Business、Market Agent及真实市场数据仍不可用；
- LLMProvider未进入生产链路，ReportGenerator仍为Mock格式化实现；
- 规则分不是下跌概率，不构成投资建议；
- 尚不支持扫描型PDF/OCR和统计预测模型。

完整验收见`docs/V0.2_RELEASE_ACCEPTANCE.md`，版本复盘见`docs/V0.2_RETROSPECTIVE.md`。
