# 3. 团队工作方式

本项目采用：

> 一名技术负责人使用 Codex 连续推进代码主线，一名技术备份独立运行和测试，其他成员并行负责标注、复核、提示词评测、产品和材料。

| 角色 | 核心职责 | 不能缺少的交付物 |
|---|---|---|
| 技术负责人 | Codex任务拆分、代码主线、PR、集成和版本发布 | 可运行代码、测试、PR、版本说明 |
| 技术备份 | 第二台电脑独立安装、运行、测试和记录Bug | 安装记录、测试结果、Bug Issue |
| 财务/业务标注 | 人工标准答案和风险标注 | 数值、页码、原文、风险判断 |
| 法务/第二复核 | 法务标注、交叉复核和提示词评测 | 条款状态、复核记录、Prompt对比 |
| 产品与材料 | 页面验收、案例、报告、PPT和演示 | 截图、操作说明、案例和演示材料 |

- [ ] 任何具体数字必须能追溯到 Evidence
