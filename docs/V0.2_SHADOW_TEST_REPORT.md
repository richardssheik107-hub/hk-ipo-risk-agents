## 2. 自动测试方法

批处理通过`IPO_RISK_COMPETITION_DATA_ROOT`定位赛事数据目录，从年度ZIP中一次临时解压一份PDF，并调用现有：

- `PyMuPDFDocumentParser`；
- `KeywordDocumentRetriever`；
- 查询“现金及现金等价物”；
- 查询“经营活动现金流”。

单个样本失败不会中断其余样本。临时PDF在单份测试结束后删除，原始PDF和结果CSV不提交Git。

运行命令：

```powershell
$env:PYTHONPATH = "src"
$env:IPO_RISK_COMPETITION_DATA_ROOT = "<赛事数据根目录>"
python scripts/run_shadow_tests.py
```

本地结构化输出：

```text
reports/v0.2_shadow_parser_results.csv
reports/v0.2_shadow_retriever_results.csv
```
