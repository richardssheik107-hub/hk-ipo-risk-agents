```powershell

```

## 7. A2.6正式报表定位整改

### 7.1 整改范围

A2.6只修改确定性关键词Retriever及其测试、影子测试查询和评测记录，没有进入财务数值抽取，也没有修改公共Schema、Workflow、Service、Agent、Skill、Verifier、Predictor或UI。

通用整改包括：

- 将现金语义区分为普通现金余额、现金流量表期末现金和经营活动现金流；
- 影子测试明确查询“现金流量表期末现金及现金等价物”；
- 为综合、合并及英文现金流量表标题建立`标题页 + 0—4页`页面邻域；
- 为会计师报告、历史财务资料、数字密度、单位和多期数据增加可解释权重；
- 为年初现金、现金净增减、汇率影响和年末现金组合上下文加分；
- 对概要、流动资金说明、风险因素、会计政策、信用风险及现金附注降权，但不删除其交叉验证价值；
- 支持港股报表常见的“产生╱（所用）”“（所用）╱所得”复合表头；
- 允许正式报表用具体报告日期表达期末现金，不要求必须出现“期末”或“年末”字样。

所有规则均与公司名称、股票代码和物理页码无关。
